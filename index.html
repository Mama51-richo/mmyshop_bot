    API Reference

    Base URL: /api (intercepted by Service Worker or fetch fallback)

    Auth: Include Authorization: Bearer <token> for protected routes.

    GET    /api/items          → list (paginate, sort, filter)
GET    /api/items/:id      → single item
POST   /api/items          → create (returns 201 + Location)
PUT    /api/items/:id      → full update
PATCH  /api/items/:id      → partial update
DELETE /api/items/:id      → delete
POST   /api/login          → { username, password } → { token, user }
POST   /api/logout         → (clear token)
GET    /api/health         → { status: 'ok' }

    Example fetch:

    fetch('/api/items', {
  headers: { 'Authorization': 'Bearer token' }
})
.then(r => r.json())
.then(console.log);

    Admin route: DELETE /api/items (bulk) with ids array.
